# 🌍 VPN TrustTunnel Manager

[![Python 3.8+](https://img.shields.io/badge/Python-3.8+-blue.svg)](https://www.python.org/downloads/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Windows](https://img.shields.io/badge/Platform-Windows-0078d4.svg)](https://www.microsoft.com/windows)
[![Multilingual](https://img.shields.io/badge/Languages-RU%20%7C%20EN-brightgreen.svg)](#-языки)

Простое и удобное графическое приложение для управления VPN-подключением TrustTunnel с поддержкой нескольких стран, геолокацией и двуязычным интерфейсом.

---

## ✨ Возможности

### Основной функционал

- ✅ **Быстрое подключение/отключение VPN** - одна кнопка для управления
- 🌐 **Поддержка 8+ стран** - выбирайте сервер среди множества локаций:
  - 🇳🇱 Нидерланды
  - 🇱🇻 Латвия
  - 🇺🇸 США
  - 🇩🇪 Германия
  - 🇫🇮 Финляндия
  - 🇨🇿 Чехия
  - 🇪🇪 Эстония
  - 🇷🇺 Россия

### Улучшенный интерфейс

- 🎨 **Темный режим** - удобный интерфейс в стиле материального дизайна
- 🌐 **Двуязычность** - поддержка русского и английского языков с быстрым переключением
- 📊 **Индикаторы статуса** - визуальное отображение состояния подключения
- 📋 **Логирование в реальном времени** - следите за процессом подключения
- ℹ️ **Встроенная справка** - информация о конфигурационных файлах и требованиях

### Информация о подключении

- 📍 **Геолокация** - автоматическое определение вашего IP-адреса, страны и города
- 🌍 **IP-информация** - отображение текущего IP при подключении к VPN
- ⚡ **Мгновенное обновление** - информация обновляется сразу после подключения

### Администраторские возможности

- 🔒 **Проверка безопасности** - предупреждение о необходимости запуска от администратора
- ✔️ **Валидация файлов** - автоматическая проверка наличия необходимых конфигураций и исполняемых файлов
- 📂 **Портативность** - приложение работает из любой директории

---

## 📦 Требования

### Системные требования

- **ОС**: Windows 7 и выше (рекомендуется Windows 10/11)
- **Архитектура**: x86 или x64
- **Права**: Администратор (обязательно для работы VPN)
- **Память**: минимум 256 MB свободного места

---

### Дополнительно

- `trusttunnel_client.exe` - клиент TrustTunnel (должен находиться в одной папке с приложением)
- Файлы конфигурации `.toml` для каждой страны (автоматически проверяются при запуске)

---

## 🚀 Установка

### Вариант 1: Использование готового EXE (Рекомендуется)

1. Загрузите последний релиз: [Releases](https://github.com/mobitop/trusttunnel/releases)

2. Скопируйте туда, где лежит trusttunnel и конфигурации:

Например: C:\VPN

├── vpn_manager.exe
├── trusttunnel_client.exe
├── ned.toml
├── lat.toml
└── ... (остальные .toml файлы)

3. **Важно**: Запустите `vpn_manager.exe` от имени администратора
- Правый клик на файл → "Запустить от имени администратора"

VPNManager (класс)
├── UI слой (Tkinter)
│   ├── Заголовок
│   ├── Выбор страны и языка
│   ├── Кнопки управления
│   ├── Индикаторы статуса
│   ├── Информация об IP

│
├── Бизнес-логика
│   ├── Управление подключением (subprocess)
│   ├── Проверка файлов
│   ├── Получение геолокации (ip-api.com)
│   └── Валидация конфигов
│
└── Система переводов
    ├── Русский (RU)
    └── Английский (EN)
Основные методы
Метод	Описание
setup_ui()	Инициализация интерфейса
connect_vpn()	Запуск VPN подключения
disconnect_vpn()	Отключение VPN
get_ip_info()	Получение геолокации через IP
check_required_files()	Валидация конфигов при старте
update_ui_language()	Обновление интерфейса при смене языка
log()	Вывод сообщений в логи
Поток выполнения подключения
1. Пользователь нажимает "Включить VPN"
   ↓
2. Валидация выбранной страны
   ↓
3. Запуск trusttunnel_client.exe в отдельном потоке
   ↓
4. Логирование вывода процесса в реальном времени
   ↓
5. При успешном подключении → запрос IP информации
   ↓
6. Обновление UI с информацией о подключении

❓ FAQ
Вопрос: Приложение требует администратора. Почему?
Ответ: VPN-подключение требует прав администратора для изменения сетевых параметров системы. Это нормальное поведение.

Вопрос: Где взять файлы конфигурации .toml?
Ответ: Файлы конфигурации обычно предоставляются вместе с клиентом TrustTunnel или должны быть загружены с официального сайта провайдера.

Вопрос: Консольное окно всё равно появляется при запуске EXE
Ответ: Убедитесь, что использовали флаг --windowed при компиляции:

bash
pyinstaller --onefile --windowed vpn_manager.py
Вопрос: Приложение не видит файлы конфигурации
Ответ:

Проверьте, что все .toml файлы находятся в одной папке с vpn_manager.exe
Убедитесь в правильности названий файлов (должны быть строчные буквы)
Попробуйте перезапустить приложение
Вопрос: IP информация не загружается
Ответ:

Проверьте интернет-соединение
Убедитесь, что VPN подключение установлено
Попробуйте отключить и снова подключиться
Вопрос: Как отключить сообщения в логах?
Ответ: Отредактируйте методы log() и check_required_files(), комментируя ненужные строки self.log(...).

⚠️ Известные проблемы
Проблема 1: Программа "зависает" при подключении
Симптомы: Окно не реагирует на клики, логи не обновляются

Решение:

Это нормально - подключение к VPN может занять 10-30 секунд
Подождите, не закрывайте окно
Если зависает дольше, нажмите "Отключить" и попробуйте снова
Проблема 2: Ошибка "trusttunnel_client.exe не найден"
Симптомы: При старте видна ошибка в логах

Решение:

Проверьте, что файл находится в одной папке с приложением
Убедитесь в правильности названия (точное совпадение случая букв)
Переместите приложение ближе к корню диска (избегайте глубоких путей)
Проблема 3: При переключении языка некоторые элементы не обновляются
Решение: Это может быть проблема с кэшированием. Закройте и откройте приложение заново.
